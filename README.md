# Hello OSS

## Giới thiệu

Hello OSS là một dự án C đơn giản dùng để thực hành phát triển và đóng góp cho dự án mã nguồn mở.

## Mục tiêu

- Làm quen với Git và GitHub.
- Thực hành viết tài liệu cho dự án OSS.
- Thực hành biên dịch và chạy chương trình C.

## Yêu cầu

- Ubuntu/Linux
- GCC
- Git

## Build và chạy

Biên dịch chương trình:

gcc main.c -o hello
